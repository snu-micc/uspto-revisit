- **Data.** The released population artifact `grants_issue.zip` is derived

  `analysis/data/DATA_LICENSE.md`). The source imposes no ShareAlike or
  attribution condition, so the license of this artifact and of other data
  files (for example the benchmark annotations) is the authors' choice; CC0,
  CC BY 4.0 or keeping CC BY-SA 4.0 are all possible.
- **Dependencies.** LocalMapper (the optional `mapping` extra) is licensed
  separately under CC BY-NC-SA 4.0. It is installed as a dependency, not
  vendored, so it does not constrain the license of this code. Users who
  install it must still follow its non-commercial terms.
- **Model outputs.** The files in `result/model_outputs/` contain text
  generated by third-party LLM services and should be covered by the data
  license chosen above, subject to the providers' terms.
